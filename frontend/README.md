# Frontend

Elm app bundled with [Vite](https://vite.dev) via [vite-plugin-elm](https://github.com/hmsk/vite-plugin-elm).

| Command         | Description                                                  |
| --------------- | ------------------------------------------------------------ |
| `npm ci`        | Install dependencies                                         |
| `npm start`     | Dev server on http://localhost:3001 (backend expected on :3000) |
| `npm run build` | Production build into `build/`, which the backend serves     |
| `npm test`      | Run the Elm tests in `tests/` with elm-test                  |
